Sobre esta demonstração

O MacanAuto v0.3 é um protótipo estático para GitHub Pages.

Funcionalidades disponíveis: cadastro, edição, exclusão e busca de veículos fictícios, indicadores automáticos e prévia de vistoria.

Os cadastros são armazenados somente neste navegador, utilizando localStorage. Eles não são sincronizados entre computadores.

Ainda não possui: autenticação, banco de dados central, QR Code, armazenamento de fotografias, vistorias reais ou integração com Microsoft 365.

Não utilize dados pessoais ou corporativos reais. O repositório é público.
