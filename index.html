Sobre esta demonstração

Esta versão é um protótipo estático para GitHub Pages, feito para testar navegação e aparência sem instalar programas.

Não possui: login, banco de dados, sincronização, cadastro persistente, armazenamento de fotos, QR Code ou integração com Microsoft 365.
